# Data card

Responsible-AI properties: **robustness** of prompt-level copyright guardrails against non-cooperative
users (Track 1) and **fairness** toward creators, i.e. whether protection against style mimicry is
provided at all and provided equally across artist groups (Track 2).

All sources are downloaded at pinned commits by `scripts/prepare_data.py` and verified against
`data/SOURCES.lock.json` (16 files, 0.8 MB). Manifests in `data/manifests/` are committed. Splits are
fixed (seed 347): **dev** is used for pilots, prompt/threshold tuning and attack development; **test**
is reported. No model is trained on these data; "train" splits exist only for the Track 2 style
classifier (WikiArt, below).

## 1. `memorized_sd1` — prompts memorized by Stable Diffusion v1.4

| | |
|---|---|
| Source | Webster 2023 (black/white-box extraction) → Wen et al. ICLR'24 `sdv1_500_memorized.jsonl` → NeMo NeurIPS'24 `memorized_laion_prompts.csv` (same 500 prompts, same order; checked on build) |
| Size / split | 500 prompts; dev 100 / test 400, stratified by memorization type |
| Ground truth | the LAION training image behind each caption (URL); downloaded on demand into `$GD_DATA_ROOT/gt_images/sd1`, never committed |
| Use | exact-copy extraction (Track 1a), memorization detector (Wen et al.), neuron probe (NeMo) |

Attributes (columns):

| column | meaning | distribution |
|---|---|---|
| `mem_type` | NeMo label: VM verbatim / TM template memorization | VM 112, TM 388 |
| `webster_type` | Webster label: MV matching verbatim, RV retrieval verbatim, TV template verbatim, N none | TV 333, MV 89, RV 36, N 14, unlabeled 28 |
| `numdups` | duplicate count of the image in LAION (Webster; −1 unknown) | median VM 210, TM 10 |
| `ref_mean_sscd`, `ref_max_sscd` | SSCD of SD v1.4 generations to the original (NeMo) | median VM 0.78, TM 0.06 |
| `n_clip_tokens` | length in SD's CLIP tokenizer | median 15–17, max 42 (all fit the 75-token window) |
| `url`, `laion_index` | provenance | |

Notes. NeMo and Webster disagree on 87 of the 472 jointly labeled prompts (28 NeMo-VM are
Webster-TV, 45 NeMo-TM are Webster-MV/RV, 14 are Webster-N); we keep both and use NeMo's label as primary because its SSCD statistics were computed
on these exact prompts. Ground-truth availability is skewed: on the dev split 77/100 source URLs were
alive on 2026-10-14, but only 9/22 for VM (dead news/media links) vs. 68/78 for TM (product pages).
Wen et al.'s Google Drive copy of the ground truth can fill the VM gap (`docs/MARKOV.md`).
Some captions name public figures (news photos); generated images are not shared.

## 2. `unmemorized_laion` — controls

500 non-memorized LAION captions from NeMo (`unmemorized_laion_prompts.csv`), same caption
distribution as §1; dev 100 / test 400. The test split also calibrates the neuron probe (see
`scripts/run_neurons.py`: template-matched z-scores).

## 3. `memorized_sd2` — prompts memorized by Stable Diffusion v2

Webster 2023 `sdv2_bb_edge_groundtruth.parquet`, filtered to memorized rows: 219 prompts
(4 MV + 215 TV; `mem_type` VM 4 / TM 215), dev 44 / test 175. Used with the SD 2-base mirror, and
to replicate Reißinger et al.'s SD 2 setting.

## 4. `copycat_characters` — copyrighted characters (He et al., ICLR'25)

| | |
|---|---|
| Source | `princeton-nlp/CopyCat` @ 49df509 (prompts only; no images are distributed) |
| Size / split | 50 characters from 18 studios; dev 11 / test 39, stratified by origin region |
| Use | indirect-anchoring lures (attacks), He et al.'s mitigations (defenses), DETECT/CONS |

| column | meaning |
|---|---|
| `target`, `prompt` | character name (the direct request) |
| `desc60` | GPT-4 60-word description without the name — the description lure. Median 77.5 CLIP tokens; **32/50 exceed SD's 75-token window on their own** |
| `kw_lm5`, `kw_laion5`, `kw_embedding5` | 5 keywords: LM-ranked, LAION-2B co-occurrence, embedding similarity |
| `gpt4_rewrite_name`, `gpt4_rewrite_desc60` | He et al.'s GPT-4 rewrites under the DALL·E policy (defense D4). Median 102 CLIP tokens; 48/49 exceed the window |
| `key_entity` | entity checked by the CONS metric (e.g. "Mermaid") |
| `origin_region`, `rights_holder` | US 36 / JP 13 / CA 1; best-effort rights holder (verify against He et al. App. B) |
| `pd_note` | 10 characters whose original version is public domain in the US (e.g. Steamboat Willie Mickey, 1926 Pooh, folk-tale princesses) while the studio design is not |

Known issues in the CopyCat release (handled in `data.py`): "Sponge Bob" vs. "SpongeBob SquarePants"
and "baby yoda" vs. "Yoda" across files; `targets_dalle_prompt.csv` contains "Steve" instead of
"Link", so Link has no GPT-4 name rewrite (regenerated by our rewriter); EmbeddingSim keywords are
noisy by construction (e.g. Doraemon → "debonair, Wartortle, Asgardian, porous, Gerudo") and are
used as released.

Kim et al. (ICML'24 workshop) built a 100-image VioT set (product, logo, character, art,
architecture × 20) but released only one example row; we reuse their APGP attack procedure on
CopyCat and the memorized prompts instead.

## 5. `artists` and `style_prompts` — Track 2

25 artists in three groups; 10 prompts each (250) over the proposal's four structural templates
(simple ×3, two-entity ×2, entity–attribute ×2, entity–scene ×3; identical content across artists so
artists are compared on paired prompts). Templates 1 and 7 are dev, the rest test.

| group | artists | reference images |
|---|---|---|
| living (core target, 10) | Kelly McKernan, Tyler Edlin, Kilian Eng (Pham et al. ICLR'24 / ESD), Greg Rutkowski, Karla Ortiz, Sarah Andersen, Hollie Mengert, Loish, Simon Stålenhag, Artgerm | **none collected** |
| deceased, in copyright (extension, 5) | Thomas Kinkade (Pham et al.), Pablo Picasso, Salvador Dalí, Andy Warhol, M.C. Escher | WikiArt (4 of 5) |
| public domain (control, 10) | Van Gogh, Monet, Rembrandt, Hokusai, Klimt, Cézanne, Munch, Goya, Seurat, Dürer | WikiArt |

Attributes: `group`, `country`, `death_year`, `latest_work_year`, `dalle_policy_allows_name` (the
DALL·E rewrite policy lets a name through only if the artist's latest work predates 1912 — 7 of the
public-domain artists; Monet, Klimt and Munch are public domain but blocked by the policy),
`wikiart_label`, `prior_work`. The living list follows the closest references plus the plaintiffs in
*Andersen v. Stability AI* and widely reported mimicry cases; it is a proposal for the team to finalize.

Why no living-artist portfolios: collecting them would reproduce the very harm under study. Style
replication for living artists is measured with CLIP zero-shot attribution among all 25 artists and
with style similarity (CSD/CLIP) to the model's own undefended outputs. WikiArt (`huggan/wikiart` @
d559852, 81,444 images, 129 artists; non-commercial research use) provides reference images for the
other two groups and the train/val/test data for a style-attribution probe.

## 6. Generated data

`outputs/` (or `$GD_OUTPUT_ROOT`) holds generated images, `records.jsonl` (prompts actually sent to the
model, negative prompt, token-window statistics, probe summaries) and per-step probe arrays (`probes/*.npz`).
Not committed; kept in private course storage.
